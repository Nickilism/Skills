# Book Comprehension Quiz

为指定书籍生成一份**分级选择题测验**，检测孩子对情节的理解，并给出蓝思值方向性参考和后续阅读推荐。核心用户场景：家长陪孩子读完一本英文分级读物（如 Magic Tree House），想知道孩子有没有真读懂、大概是什么阅读水平、接下来该读什么。

## 核心原则（不可违反）

1. **禁止编造情节和数据。** 出题前必须先用 web_search / web_fetch 核实这本书的情节细节、官方蓝思值（Lexile）、AR分值等信息。不要仅凭训练记忆里的模糊印象编题——记忆可能有细节错误，会直接误导孩子和家长。如果搜索结果互相矛盾或不充分，选择更权威的来源（出版社官网、Scholastic Book Wizard、Goodreads/图书馆书目页），并在文中如实说明不确定之处。
2. **书籍信息不足时不要瞎猜。** 如果书名、版本、系列序号有歧义（同名书、多个版本、译本），先向用户确认，或请用户上传电子版文件（PDF/epub/txt）供直接读取核实，而不是选一个猜测版本硬着头皮出题。
3. **蓝思值评估必须诚实降级预期。** 10道题的小测验**不能**像正规 Lexile 测试那样给出精确数值，必须在结果里明确声明这一点，只给方向性判断（"大概率达到/低于该书官方蓝思值"），并指向正规工具（Scholastic Book Wizard、Star Reading等）供家长需要精确数值时使用。
4. **推荐书目的阅读难度数据也要核实**，不能凭印象编蓝思值/AR值。

## 工作流程

### 第一步：确认书籍信息
- 如果用户给的书名/系列/版本清晰无歧义 → 直接进入第二步。
- 如果不确定（书名可能对应多本书、用户提到的版本/页码来源不明、或书籍较冷门搜不到可靠资料）→ 简短说明情况，请用户：
  - 确认具体版本/系列序号，或
  - 上传电子版文件（此时改用文件内容直接出题，不必再搜索情节，但仍需搜索该书的官方蛋思值/AR值用于第四步）。

### 第二步：核实情节与关键事实
用 web_search（必要时 web_fetch 具体页面，如系列 wiki、出版社简介、教师用 comprehension questions 页面）确认：
- 主要情节脉络（开头设定 → 冲突 → 关键转折 → 结局）
- 关键人物、地点、物品名称的准确拼写
- 任何书中特有的因果关系/主题，用于设计推理题

### 第三步：设计10道选择题（难度递增）
分层设计，覆盖以下考察点，大致按顺序从易到难排列（可根据具体书籍调整比例，但整体要有梯度）：
1-2. **字面细节**：谁/在哪/发生了什么明显情节点
3-5. **人物关系与因果**：为什么某角色做了某事、事件之间的因果链、关键词汇在上下文中的含义
6-8. **推理与细节整合**：需要综合多处情节才能回答，不能靠单句原文照抄找到答案
9-10. **主题/概括**：全书主旨、角色成长、隐含寓意

每题要求：
- 4个选项（A-D），只有1个正确答案
- **干扰项要合理**（用书中真实出现过的其他人物/地点/情节做干扰项，而不是一眼假的选项），否则测不出真实理解，只是测出常识
- 10题中同一字母答案（A/B/C/D）出现次数不超过3-4次，整体分布尽量均匀，避免孩子靠"蒙B"拿高分
- 每题标注难度/考察点标签（如 easy-literal / medium-inference / hard-theme），方便家长看出错误集中在哪个能力层

### 第四步：输出格式

生成一份 Markdown 文件（用 create_file，因为内容较长，含标题结构、答案解读、荐读书单，属于适合存档的完整文档），结构如下：

```
# 书名 — Reading Comprehension Quiz
简短说明 + 使用建议（让孩子独立作答，不要读给他听，这样结果更接近真实独立阅读水平）

## Q1 ~ Q10（每题标注难度标签）

## 答案 Answer Key
简洁列出正确答案

## 评分与解读建议
按对题数分档给出解读（例如 9-10题/7-8题/6题及以下 分别说明）

## 关于"蓝思值测验"的说明
必须包含：
- 声明10题测验≠正规蓝思测试，只能方向性参考
- 列出该书官方蓝思值/AR值（核实后的真实数字，标注来源可信度）
- 根据孩子表现给出"可能高于/接近/低于该数值"的判断逻辑
- 提示如需精确数值，可用 Scholastic Book Wizard 或学校/图书馆的 Star Reading 测试

## 后续阅读推荐
- 分类给出：同系列相近难度书目 / 主题相近但难度稍低（巩固用）/ 同档次横向拓展系列
- 每本书标注核实过的蓝思值或年级水平，不确定的要注明"约"或给出年级区间而非假装精确
```

生成后调用 present_files 呈现给用户；不需要额外长篇解释，简要说明这次测验设计的重点即可（例如难度梯度、答案分布），不要重复输出文件全文。

### 已知上下文校准（如适用）
如果 Claude 的记忆里有该孩子的年级/英语水平信息，据此校准题目语言难度和选项措辞（例如"五年级英文中等水平"的孩子，题干本身也应该是他能独立读懂的英文，不要用超纲词汇出题干）。如果没有相关记忆，按该书/系列官方标注的目标年龄段来定题干难度。

## 反面示例（不要这样做）
- ❌ 没有搜索就凭记忆写出"某角色骑着龙飞走了"这种可能记错的情节题
- ❌ 10题里有7题正确答案都是C
- ❌ 直接报出"孩子的蓝思值是605L"这种伪精确的数字，而不说明这只是方向性推测
- ❌ 推荐书单里的蓝思值是编的，没有实际核实
