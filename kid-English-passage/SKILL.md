# 五年级英文短文生成 Skill

## 目的与读者

- 读者:五年级孩子,英文水平中等(能读懂简单段落、可以有一些复合句,但不适合生僻词汇或长难从句)。
- 用途:**双重用途** —— 大声朗读/跟读练习 + 读完之后讨论内容、锻炼口头表达观点。文章必须既适合朗读出声(句子有节奏感、不拗口),又要在结尾留出可讨论的空间。

## 固定结构(三段式)

1. **具体场景或意象开头**:用一件小事、一个具体情境、一个自然现象或类似的画面开场,而不是抽象说教。让孩子朗读时有画面感。
2. **展开为一层普遍的思考**:把开头的具体意象引向一个更普遍的道理(成长/坚持/自我认识等)。用2-3句稍微复合一点的句子,给孩子一点"够得着的挑战",但不要堆砌从句。
3. **开放式结尾**:留一到两个开放性问题,引导孩子自己表达观点,而不是替她把道理说死。问题最好有层次(先问观点,再问她自己的经历/例子)。

## 硬性要求

- **长度**:150-250词。
- **语气**:温暖中带一点正式感,不幼稚、不说教。
- **加粗**:全文加粗2-3句"核心句子"——分别对应"顿悟句"(第一段结尾附近)和"点题句"(第二段核心道理),方便孩子重点朗读、记忆、讨论时定位。
- **生词提示**:文末附1-2个对该水平孩子稍微跳一跳能够到的生词,给出**极简英文释义**(不要中文翻译,保持全英文语境),格式如下:

  ```
  ---
  *New words:*
  **unexamined** — not looked at carefully or thought about
  **wobble** — to move unsteadily from side to side
  ```

  生词应该是文中已经出现的词,不要额外引入新词汇。

## 避免重复(重要)

每次生成前,回顾本次对话中已经用过的:
- **主题**(如已用过"好奇心"、"失败与尝试",下一篇换新主题,可参考主题池)
- **人物名字**(如已用过 Mia、Leo,下一篇换新名字、可以换性别)
- **叙事视角**(不要每次都是"小孩+长辈/朋友对话+顿悟"的套路,可以换成自然观察、动物、日常小事、孩子的内心独白等不同切入方式)

**主题池参考**(不限于此):坚持与耐心、失败与尝试、好奇心与提问、独处与自我认识、友谊与理解、诚实与勇气、专注与分心、感恩与知足、变化与成长、倾听与共情。

## 输出格式示例

```
**标题**

[第一段:场景开头,含一句加粗的顿悟句]

[第二段:展开道理,含一句加粗的点题句,2-3句稍复合的句子]

[第三段:简短收束,可选]

[开放式讨论问题,1-2句]

---
*New words:*
**词1** — 简易英文释义
**词2** — 简易英文释义
```

## 语气与用词检查清单(生成后自查)

- 句子是否适合朗读出声?有没有拗口或过长的从句?
- 加粗的2-3句是否真正是全文最值得记住的句子?
- 结尾问题是否足够开放,能让孩子说出自己的真实想法/经历,而不是复述文章观点?
- 主题、人物、切入角度是否与之前生成过的重复?
- 生词是否确实出现在正文中,释义是否用简单英文(不用更难的词解释生词)?
